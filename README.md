# Interpolación: Lagrange vs. Diferencias Divididas de Newton

Práctica Tarea 1 Unidad 5, SCC-1017 Métodos Numéricos, ITSX.

## Descripción
Proyecto en Java que implementa la interpolación polinomial con el método de Lagrange y con diferencias divididas de Newton, y compara sus resultados para un mismo punto.

## Requisitos
- Java: OpenJDK 26.0.2
- IDE: IntelliJ IDEA 2026.2.2

## Cómo ejecutarlo
1. Clonar el repositorio: `git clone https://github.com/TU_USUARIO/interpolacion-lagrange-newton.git`
2. Abrir la carpeta en IntelliJ IDEA.
3. Ejecutar `src/interpolacion/Main.java`.

## Datos de prueba
- Nodos x: 3, 6, 9, 4
- Valores y: 5, 7, 2, 8
- Punto de evaluación: x = 5

## Archivos
- `InterpolacionLagrange.java`: método de Lagrange.
- `InterpolacionNewton.java`: diferencias divididas de Newton.
- `Main.java`: prueba con nodos propios y comparación de resultados.
